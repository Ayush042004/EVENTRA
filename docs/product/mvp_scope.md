# MVP Feature Taxonomy & Scope

## In Scope (KEEP)
- Event Setup & Specification
- Venue Discovery & Spatial Capability
- Provider / Vendor Network & Assignment
- Planning & Dependency Engine (DAG)
- Live Command Center & State Telemetry
- Incident Detection & Intake
- Impact Analysis (Blast Radius)
- Risk Engine (Objective Threat Scoring)
- Recovery Engine (Alternative Synthesis & Feasibility)
- Human Approval Workflows & Thresholds
- Autonomous Operations (Pre-authorized limits)
- Procurement & Supply Tracking
- Real-time Notifications & Alerts
- Mobile PWA Interface
- Post-Event Analytics & Immutable Audit
- Single Event Operations Agent (LangGraph)
- Real-World Integrations (Maps, Push, WhatsApp stub)
- Verification Closed-Loop

## Special Doubt / Doubt
- WhatsApp Provider Messaging (Isolated in integration layer behind feature flags)
- Audit Trust Proofs (Basic relational audit kept; crypto trust deferred)
- Cross-Event Organizational Learning & Long-Term Memory (Deferred post-MVP)

## Strictly Forbidden (REMOVE)
- Attendee profiles & individual attendance tracking
- RSVP ticketing platform
- Social activity feeds
- Full enterprise Cvent clone
- Generic chatbot
- Autonomous payments
- Multi-agent proliferation (Ten-Agent architecture)
